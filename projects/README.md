# 프로젝트별 지침 연결

공통 규칙은 이 저장소에서 재사용하고, 코드 구조·개발 규칙·테스트·저장소 간 계약은 대상 프로젝트에서 관리한다. 도구가 이 저장소를 자동으로 읽는다고 가정하지 않는다.

## 상위 폴더 아래 복수 저장소

가상 구조:

    product/
      AGENTS.md
      .ai-workflow-startup.json
      backend/
        AGENTS.md
        .git/
      mobile/
        AGENTS.md
        .git/

상위 지침에는 공통 목표·API/데이터 계약·저장소별 담당 범위·통합 완료 기준을 둔다. 각 저장소 지침에는 실제 경로·언어/도구 버전·개발 규칙·테스트 명령·생성물·변경 금지 범위를 둔다. 양쪽 저장소에 걸친 업무는 상위 조율자가 의존성·계약 변경·통합 검증을 취합한다.

[시작 설정 양식](../templates/project.startup.json)은 가상 backend/mobile 경로를 사용한다. 실제 구조를 확인한 뒤 바꾸며, 지정한 지침 파일이 없으면 시작은 오류다. 이름만 보고 저장소 경로나 테스트 방법을 추정하지 않는다. 상위 폴더 자체가 Git 저장소일 필요는 없다.

scripts/startup.py --project <상위 폴더>는 공통·환경 가이드와 상위/자식 지침 경로를 구분해 반환한다. 해당 도구의 지침 기능이나 역할별 작업 전달에 필요한 문서를 명시적으로 포함한다. 한 저장소 담당자에게 다른 저장소의 불필요한 내부 자료를 모두 전달하지 않는다.

이 최소 구성은 명시한 상대 경로·문서 존재와 경계를 확인할 뿐, 실제 Git remote·작업 공간·테스트 성공·환경 등록을 확인하지 않는다. 각 환경 가이드에서 target을 확인한 뒤 작은 읽기 전용 업무부터 적용한다.

실제 프로젝트의 절대 경로·등록 ID·계정·원문 실행 자료는 해당 프로젝트 또는 합의한 비공개 위치에 둔다. 이 공개 저장소에는 범용 지침과 가상 연결 예시를 유지한다.
