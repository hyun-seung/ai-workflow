# 튜터 심화·추천 품질 1차 자체 평가

상태: 2026-11-13 대표 응답의 자체 검토와 로컬/화면 확인 완료. 독립 평가·블라인드 시험·사용자 학습 효과·실사용 오분류율·토큰 절감은 미검증이다. [통합 개발 순서](development.md)의 2단계에서 확인한 범위와 제한을 기록한다.

## 방법과 완료 기준

Python 객체 복사, HTTP 캐시, PostgreSQL 트랜잭션 세 주제에 대해 [가상 요청과 생성 응답 16개](evaluation-responses.md)를 작성하고, 같은 작성 AI가 다음 기준으로 검토했다. 실사용 대화나 비공개 프로젝트 내용은 사용하지 않았으며 분류·평가 전용 AI를 추가 호출하지 않았다. 현재 작성 AI의 실제 모델·effort·전체 토큰을 별도 수집하지 않았으므로 값을 추정하지 않는다.

1. 요청한 방식과 분량에 맞는가? 쉬운 말·원리·관계·예외가 일치하는가?
2. 사실을 공식 문서의 해당 절이 실제로 뒷받침하는가? 재구성·비유·직접 만든 수치가 구분되는가?
3. 모르는 자료·불명확한 대상·잘못된 전제에 대해 지어내거나 상향 추천하지 않는가?
4. 질문을 기다리는 파인만 방식과 질문·답을 함께 주는 Q&A를 구분하는가?
5. 작은 설명·후속 요청에서 불필요한 역할 승인·모델 전환·별도 worker가 없는가?
6. 그림의 분류·흐름·단위·분기가 정확하고 실제 화면에서 읽을 수 있는가?

판정은 아래의 확인 범위에 한정한다. 응답 작성자가 기대 결과와 기준을 알고 있으므로 모든 항목이 적합해도 일반화 정확도를 계산하지 않는다. 반복·독립 평가에서 재현되는지와 사용자가 이해하기 쉬운지는 별도다.

## 실행·화면 확인

- [통합 입력 12개](../examples/tutor-routing-cases.json)의 작성된 해석을 로컬 라우터에 넣어 기대 정책 경로와 대조했다. 이는 입력된 해석의 정책 검사이며 자연어 의도를 자동으로 맞힌 12회가 아니다.
- TE-15의 모델/effort 고정·위임 금지에서 역할만 제안하는 경로를 별도로 확인했다. `executable=false`이며 실행·설정 변경은 없다.
- TE-14의 Python 코드 1개를 실행해 assertion을 확인했다. PostgreSQL 서버·HTTP 서버 통합 시험은 수행하지 않았으며 해당 개념은 공식 원문으로 확인했다.
- [시각 예시 HTML](visual-samples.html)의 네 탭을 Orca 브라우저에서 1000px·390px 폭으로 확인했다. 네 방식 모두 가로 넘침 없이 선택한 패널 하나만 표시됐다. 마인드맵·도식·메모·학습 시트의 스크린샷을 직접 확인했다.
- 한 장 시트의 좁은 화면 초안은 본문 높이 약 890px로 길었다. 수정 후 390×844 화면에서 가로 넘침이 없고 하단 안내까지 포함한 끝 위치가 약 720px였다. 이는 해당 예시의 배치 결과이며 모든 시트를 같은 화면에 넣는 보장은 아니다.
- 탭의 Home·ArrowRight 전환으로 마인드맵 선택을 확인했다. 스크린리더 전수 검사·모든 브라우저·모든 테마·초소형 화면 검증은 수행하지 않았다.

시각 확인용 탭은 작업 종료 때 닫으며, 소스 HTML과 채팅용 미리보기만 유지한다. 원시 연결 상태·스크린샷 경로·개인 세션 정보는 공개 문서에 넣지 않는다.

## 반영한 보완

- 그림·시트가 주된 요청일 때 같은 내용을 긴 본문·Q&A로 반복하지 않도록 튜터 지침 보완.
- 마인드맵 연결선, 모바일 학습 시트 배치, 키보드 탭 선택 보완.
- 기존 [참고 답변](reference-response.md)의 안쪽 객체 공유 설명을 얕은/깊은 복사를 직접 설명하는 공식 copy 문서로 연결.
- ELI5 기본 응답의 연관 Q&A 누락 보완. 짧은 요청에는 여전히 Q&A를 강제로 붙이지 않음.

## 다음 단계와 미검증

현재 범위의 자체 검토에서는 진행을 막는 설명·정책·배치 문제를 보완했다. 다음은 **Orca 입력과 대화 상태의 최소 비용 연결**이다. 이 결과만으로 자동 위임·모델 선택을 켜거나 추천 품질이 보장됐다고 간주하지 않는다.

독립 평가·블라인드 입력·비기술 주제·반복 실행·사용자 이해도·실제 추천 빈도·전체 시간과 토큰 비교는 남아 있다. 향후 연결된 실제 결과도 같은 기준으로 점검하며, 설명 오류나 불필요한 추천이 나타나면 해당 단계의 규칙·판단을 수정한다. 이 문서를 일반 요청마다 모델에 주입하지 않는다.
