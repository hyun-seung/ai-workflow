# 튜터 참고 답변과 자체 점검

공개용 가상 질문에 대해 이 지침을 작성한 AI가 구성한 참고 예시다. 사용자 원문이나 독립 모델 실험 기록이 아니며 답변 품질·학습 효과·모델 간 우열의 측정 결과로 사용하지 않는다. 공식 Python 튜토리얼의 관련 절을 확인하고 아래 코드의 결과를 로컬에서 대조했다. 확인 날짜는 2026-11-13이며 링크의 기본 Python 버전은 이후 바뀔 수 있다.

## 기본 설명

가상 요청: “Python에서 `b = a`로 리스트를 복사했는데 왜 같이 바뀌어? 쉽게 설명해 줘.”

아래는 공식 문서 내용을 쉬운 말로 재구성한 설명이다. 이름표 비유와 코드는 이해를 위해 직접 구성했다.

`b = a`는 리스트를 복사하지 않고 **같은 리스트에 이름을 하나 더 붙이는 것**이다. `a`와 `b`로 같은 리스트를 바꾸므로 두 이름에서 바뀐 내용이 보인다. [Python 공식 튜토리얼: Lists — 대입과 같은 객체 참조](https://docs.python.org/3/tutorial/introduction.html#lists)

```python
a = [1, 2]
b = a
b.append(3)
print(a)  # [1, 2, 3]
```

새 리스트가 필요하면 `b = a.copy()`를 쓴다. 바깥 리스트를 새로 만드는 **얕은 복사**다. [Python 공식 튜토리얼: More on Lists — list.copy](https://docs.python.org/3/tutorial/datastructures.html#more-on-lists)

```python
a = [1, 2]
b = a.copy()
b.append(3)
print(a)  # [1, 2]
print(b)  # [1, 2, 3]
```

이어 궁금할 만한 질문:

- **`b = a[:]`도 복사야?** 그렇다. 전체 슬라이스도 새 리스트를 만드는 얕은 복사다. [공식 튜토리얼: Lists — 슬라이스 복사](https://docs.python.org/3/tutorial/introduction.html#lists)
- **얕은 복사는 안쪽 리스트까지 새로 만들어?** 아니다. 안쪽 객체는 공유할 수 있다. 따라서 리스트 안에 리스트가 있을 때는 바깥 복사만으로 모든 변경이 분리된다고 생각하면 안 된다. [공식 copy 문서: 얕은 복사와 깊은 복사](https://docs.python.org/3/library/copy.html)

```python
a = [[1]]
b = a.copy()
b[0].append(2)
print(a)  # [[1, 2]]
```

## 분량·대화 전환 예시

가상 후속 요청: “한 줄로만 정리해 줘.”

> `b = a`는 같은 리스트를 가리키고, `b = a.copy()`는 바깥 리스트를 새로 만드는 얕은 복사다. [Python 공식 튜토리얼](https://docs.python.org/3/tutorial/introduction.html#lists)

가상 후속 요청: “내가 설명해 볼게.”

> `b = a`와 `b = a.copy()`가 어떻게 다른지 네 말로 설명해 볼래요?

두 후속 응답에는 모델/역할 변경 제안·학습 설문·불필요한 전체 재설명을 붙이지 않는다. 파인만 응답에서는 사용자 답을 대신 작성하거나 이해했다고 먼저 판정하지 않는다.
