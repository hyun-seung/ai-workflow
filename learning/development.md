# 튜터·요청 라우팅 통합 개발 순서

튜터와 역할·모델/effort 추천을 같은 진입 흐름에서 개발한다. 매 요청의 추가 토큰 최소화, 직접 처리 선택, 공식 근거와 필수 품질을 공통 기준으로 둔다. 역할 문서나 로컬 도구의 존재를 앱 연동 완료로 간주하지 않는다.

## 우선순위

| 순서 | 통합 작업 | 완료 기준과 현재 범위 |
| --- | --- | --- |
| 1 | 튜터 기본 응답·추천 생략 기준 정리와 대표 사례 점검 | 짧은 튜터 진입 지침, 공식 근거에 기반한 참고 답변, 튜터/일반 요청의 점검 입력을 작성. 로컬 라우터의 정책 경로와 코드 예시는 확인하되 자연어 추천 품질·사용자 학습 효과의 통계 평가와 구분 |
| 2 | 튜터 심화 방식·추천의 실제 품질 평가 | 원리·스티커 메모·마인드맵·도식·한 장 시트·파인만·연관 Q&A를 대표 주제에 적용. 자료 없는 질문·실제 개발 요청·설정 고정까지 포함해 불필요한 추천·오분류·출처 오류·분량 초과를 기록. 현재 AI의 자체 판단과 사용자/독립 평가를 구분 |
| 3 | Orca 입력·대화 상태 연결 | 공식 연결 지점을 확인하고 새 요청·후속 질문·제어·내용 버전을 최소 정보로 전달. 같은 튜터 설명의 후속 요청은 기존 선택 재사용. 설정 변경·다른 요청에는 재사용 무효화. 매 입력 별도 모델 호출 없음 |
| 4 | 사용자 선택과 같은 AI의 역할 적용 | 요청·제안 버전별 수용/거절/취소·만료·중복을 연결. 선택한 역할과 필요한 지침만 적용. 직접 처리·역할/설정 고정·위임 금지를 유지하고 지속 선호는 명시한 범위에만 저장 |
| 5 | 명시한 병렬 위임·모델/effort 전환 | 기존 관리 위임·한도·지원 확인·실제값 기록을 재사용. 튜터의 시각 자료/연관 Q&A도 독립 준비의 이점이 있을 때만 분리. 불필요한 worker·상향·중복 자료 탐색 방지 |
| 6 | 직접 처리 대비 비용·품질 비교와 제한 자동화 | 같은 완료 기준에서 추천·선택·출처 탐색·인계·통합·재작업까지 비교. 토큰·시간·품질의 근거가 있는 유형만 자동화 허용. 미측정은 절감으로 보고하지 않음 |

각 단계에서 튜터의 발견된 문제를 고친다. 튜터 전체를 별도 완성한 뒤 라우터를 다시 붙이거나, 모든 단계를 한꺼번에 구현하지 않는다. 현재 순서는 의존성에 따른 개발 계획이며 모델/worker 실행·지속 설정 변경의 포괄 승인이 아니다.

## 1차 산출물과 확인 범위

- [짧은 튜터 진입 지침](tutor-brief.md): 단순 설명에 맞춘 필수 행동. 심화 요청에만 상세 역할 문서 확인.
- [공식 문서 기반 참고 답변](reference-response.md): 가상 Python 질문을 재구성한 답변·짧은 응답·파인만 요청 예시. 실제 코드를 확인하되 다른 주제의 품질까지 일반화하지 않음.
- [통합 점검 입력](../examples/tutor-routing-cases.json): 작성 AI가 정리한 요청 해석과 라우터 입력·기대 정책 결과. 기대값을 알고 작성한 자체 점검 자료이며 독립 자연어 분류 시험이 아님.

1차 로컬 확인: 작성한 점검 입력 12개의 정책 결과가 기대값과 일치했고, 참고 답변의 Python 코드 3개의 출력이 설명과 일치했다. 공식 튜토리얼의 대입·리스트 복사 절을 원문 확인했다. 이는 정책 연결과 한 주제 예시의 자체 확인이며 실사용 오분류율·학습 효과·토큰 절감의 측정이 아니다.

2단계의 [대표 응답 16개](evaluation-responses.md)에 대해 세 기술 주제의 공식 근거·분량·전환·추천 필요성을 자체 검토하고 [평가 결과](evaluation.md)를 남겼다. 시각 예시 네 방식의 두 화면 폭 확인, 모바일 시트·마인드맵·키보드 전환과 지침 보완을 수행했다. 독립 추천 정확도·사용자 학습 효과·토큰 절감은 미검증이다. 다음 작업은 3번 Orca 입력·대화 상태 연결이다.

자연어에서 제어·의도·후속 여부를 추출하는 연결은 아직 없다. 로컬 도구는 전달받은 해석의 정책 준수만 검사하므로, 입력과 기대값이 맞아도 추천 의미 판단의 정확도나 토큰 절감률을 얻은 것은 아니다. 실제 품질 평가에서는 원래 요청, 사용한 지침 버전, 실제 판단/응답, 출처와 판정 근거를 연결하고 측정하지 않은 모델·effort·사용량을 추정하지 않는다. 실제 대화 기록은 지정된 비공개 위치에 보관한다.
