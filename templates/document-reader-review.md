# 문서만으로 수행한 독자 시험

- 문서 경로·hash / 독자 / 날짜 / 자체 또는 실제 독립:
- 독자 목표 / 관측할 완료 결과:
- 제공한 최종 문서 / 문서가 허용한 전제·입력:
- 구체 작업·질문 (작성자 정답·구현 힌트 제외):
- 독자의 실제 답 / 수행 결과 / 막힌 단계 / 빠진 정보:
- 문서 외 자료 사용 여부 / 미수행 범위:
- 작성자의 사후 목표 비교 / 필요한 최소 수정 / 재시험 결과:
- 생략했다면 영향과 기존 프로젝트 권한 근거:

독자의 기록 전에는 기대 답을 제공하지 않는다. 자체 확인·실제 독립 시험·구현 안전성 검토·사람 승인을 구분한다. 독자 시험 결과는 반영 승인이나 정책 결정이 아니다.
