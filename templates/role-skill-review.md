# 역할 스킬의 짧은 확인 기록

대상 프로젝트의 기존 작업 결과에 필요한 항목만 통합한다. 작은 수정에 별도 보고서를 강제하지 않는다.

- 역할·원래 AC·대상 버전:
- 스킬 ID / source commit / skill 또는 reference-only:
- 실제 읽은 규칙·수행한 검사:
- 발견 → 수정 담당·변경 → 재검증 결과:
- 기준 화면·데이터·viewport·API 모드 / Web·native 구분:
- 다음 역할에 전달할 확정 사항·참조:
- 미검증·남은 차이·도구 제약:

설치, 원문 참조, 도구 실행, 실제 화면 확인을 구분한다. 취향 제안과 AC 위반을 나누고 기존 검증 증거의 유효성을 확인한다. 실행 기록은 [정보 관리](../principles/privacy.md)를 따른다.
