- 검토자 / 역할 / 실제 검토 증거:
- 제안 ID·버전·sha256 / 대상 snapshot / 설정 hash / 정확한 파일:
- 결론: 승인 / 수정 필요 / 거절 / 보류 (하나 선택)
- 승인 범위·이유 / 지적·미결 / 사람 정책 결정 참조:
- 자체 확인 / 자동 검사 / 실제 독립 검토 / 사람 승인 / 미검증:
- 반영자 / 실제 반영 파일 / 백업 / 반영 후 검사·충돌:

도우미 review JSON 필드는 절차 문서를 따른다. 합성 시험은 synthetic=true로 표시하고 실제 승인으로 재사용하지 않는다. 변경된 제안·대상·설정에 이 결론을 재사용하지 않는다.
