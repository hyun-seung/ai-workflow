# 공통 workflow 연결

공통 저장소:
`/absolute/path/to/ai-workflow`

- 프로젝트 작업을 시작할 때 현재 작업 폴더와 대상 프로젝트 지침을 확인한다.
- 공통 저장소의 `AGENTS.md`와 `projects/README.md`를 읽고 공통 원칙을 적용한다.
- 상위 지침을 준수하며, 현재 요청과 대상 프로젝트의 구체적인 지침을 우선한다. 작업 폴더는 대상 프로젝트로 유지한다.
- 역할·환경·검증 관련 상세 문서는 해당 작업에 필요할 때만 읽는다. 이미 확인한 지침은 같은 작업에서 불필요하게 반복해서 읽지 않는다.
- 공통 저장소 자체의 수정·테스트 규칙은 그 저장소를 작업할 때만 적용한다.
- 문서를 읽을 수 없으면 적용했다고 가정하지 말고 제한을 알린다.
