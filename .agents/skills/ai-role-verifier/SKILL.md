# 검증자의 스킬 적용

[연결 기준](../../../skills/README.md)을 읽고 필요한 규칙만 선택한다. 이 파일의 위치에서 공통 저장소 루트를 확인해 `python3 /path/to/ai-workflow/scripts/skill_catalog.py select --role verifier`를 실행한다. 다른 프로젝트에서도 작업 cwd를 바꾸지 않고 전달받은 공통 저장소 절대 경로를 쓴다. 출력된 원본 경로·버전·상태·모드와 역할 적합성을 확인한다. common은 후보이며 모두 실행하라는 뜻이 아니다. 원문 참고·설치·실제 실행을 구분하고 미설치·비활성·무결성 실패는 미확인으로 보고한다.

break-ui로 실제 허용 길이·빈 목록·하나/여러 항목·누락 값을 재현한다. Web이면 --tag web, 오류 분석이면 debugging을 추가하고 필요한 Impeccable audit/native 문서만 참고한다. fixture는 데이터 경계로 넣고 제품에 남기지 않는다. 실제 화면·동작과 원래 AC로 판정하며 구현 수정은 개발자에게 기대/실제 결과·재현 근거와 함께 돌려보낸다. 수정 후 영향 조건을 재검증하고 통과/실패/미검증을 구분한다.

외부 스킬은 사용자·프로젝트 지침과 실행 환경을 우선한다. reference-only는 관련 방법만 참고하며 원문의 자동 실행 절차를 실행하지 않는다. 새로운 스킬·도구·에이전트 실행 권한을 만들지 않는다. [짧은 기록 양식](../../../templates/role-skill-review.md)을 기존 결과에 통합하고, 다음 담당자가 접근할 수 있는 산출물·계약·검증 범위·미확인을 전달한다.
