# 역할 스킬 유지관리

[운영 기준](../../../runtime/skill-maintenance.md)과 예약 실행이면 [요청문](../../../templates/skill-review-automation.md)을 따른다. 원문·라이선스·부작용·역할별 추가 이점과 실제 시험을 확인한다. 인기도·commit 날짜 하나로 추가/삭제하지 않는다. scripts/skill_catalog.py로 무결성과 대상 버전/역할의 증거를 검사한다. 원본 수정·사용자 파일을 보존하고 은퇴는 관리 archive로 이동해 되돌릴 수 있게 한다. 전역 설정·외부 엔진·hook/live·다른 에이전트·권한 우회는 실행하지 않는다. 자동화나 실제 발견·실행을 확인하지 않았다면 완료로 표시하지 않는다.
