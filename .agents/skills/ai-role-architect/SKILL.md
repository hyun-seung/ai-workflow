# 설계자의 스킬 적용

[연결 기준](../../../skills/README.md)을 읽고 필요한 규칙만 선택한다. 이 파일의 위치에서 공통 저장소 루트를 확인해 `python3 /path/to/ai-workflow/scripts/skill_catalog.py select --role architect`를 실행한다. 다른 프로젝트에서도 작업 cwd를 바꾸지 않고 전달받은 공통 저장소 절대 경로를 쓴다. 출력된 원본 경로·버전·상태·모드와 역할 적합성을 확인한다. common은 후보이며 모두 실행하라는 뜻이 아니다. 원문 참고·설치·실제 실행을 구분하고 미설치·비활성·무결성 실패는 미확인으로 보고한다.

기존 구조·SDK·API 원문에서 화면 상태와 요청/응답·오류의 대응을 정한다. 실패·복구·권한 경계, 중요한 대안·검증 방법과 파일 범위를 개발자·검증자에게 전달한다. 외부 계획 프레임워크는 기본 설치 대상이 아니며 프로젝트에 필요한 전문 스킬만 제안한다.

외부 스킬은 사용자·프로젝트 지침과 실행 환경을 우선한다. reference-only는 관련 방법만 참고하며 원문의 자동 실행 절차를 실행하지 않는다. 새로운 스킬·도구·에이전트 실행 권한을 만들지 않는다. [짧은 기록 양식](../../../templates/role-skill-review.md)을 기존 결과에 통합하고, 다음 담당자가 접근할 수 있는 산출물·계약·검증 범위·미확인을 전달한다.
