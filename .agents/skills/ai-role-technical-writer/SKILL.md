# 기술 문서 변경

이 파일에서 세 단계 위 공통 저장소 루트를 확인하고 [역할](../../../roles/technical-writer.md)과 [간결한 절차](../../../runtime/technical-documentation.md)를 읽는다. 대상 프로젝트 cwd를 유지한다. 프로젝트별 문서 루트·명시 허용 파일·출처·검토 책임·백업·환경은 대상 설정에서 읽는다.

관련 근거만 찾아 코드/설계/확인된 동작/사람 결정/미결을 나눈다. 불일치는 제안에 남기고 자동 설계 변경하지 않는다. 버전과 정확한 대상 snapshot에 결합된 검토 결론을 확인한 뒤 승인된 파일만 반영한다. 직접 처리 지시와 유효한 작은 수정 권한은 재사용하며 새 모델·에이전트 권한을 만들지 않는다.

도우미는 로컬 순차 반영 경계를 검사할 뿐 실제 검토자 신원·앱 권한을 인증하지 않는다. 자체 검사 결과를 독립 검토나 사람 승인으로 표시하지 않는다. 역할 후보가 필요할 때만 공통 저장소의 `scripts/skill_catalog.py select --role technical-writer`를 조회한다. 빈 후보는 외부 스킬 설치나 검증을 뜻하지 않는다.

독자가 수행할 작업·완료 결과를 먼저 쓰고 기존 문서의 범위와 길이를 유지해 필요한 부분만 고친다. 중요한 절차 변경에는 절차 문서의 독자 시험을 영향에 따라 선택한다. 문서·허용 전제·작업만 전달하고 저자 정답이나 구현 힌트 없이 실제 결과를 기록한다. 자체 읽기와 실제 독립 독자 시험을 구분한다. 근거 drift 도우미는 재검토 후보만 반환하며 정책 결정·보안 승인이 아니다.
