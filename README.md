# ai-workflow

**AI가 요청을 판단하고, 필요한 역할·실행·검증·기록을 이어가도록 돕는 공통 작업 체계입니다.**

작은 요청은 현재 AI가 바로 처리하고, 복잡한 작업은 목표와 완료 기준을 정리해 진행합니다. 기존 AI 앱과 프로젝트에서 사용합니다.

## 처음 사용하시나요?

쓰던 AI 앱에서 작업할 프로젝트를 열고 아래 메시지를 복사해 보내세요. AI가 현재 환경을 확인하고 **지원되는 기능을 연결할 설정안**을 안내합니다.

```text
이 프로젝트에 ai-workflow를 전체 연결해줘.
https://github.com/hyun-seung/ai-workflow

저장소의 runtime/project-onboarding.md를 읽고 진행해줘.
요청 판단부터 필요한 역할·실행·검증·기록까지 연결하고 싶어.
작은 요청은 현재 AI가 직접 처리하고,
모델 변경과 위임은 기존 허용 범위와 이번 작업의 선택을 따라줘.
현재 프로젝트와 기존 지침을 확인하고, 설정 변경 전에는 변경안을 보여줘.
읽을 수 없거나 지원하지 않는 기능은 구분해서 알려줘.
```

| 사용 방식 | 안내 |
| --- | --- |
| 내 여러 프로젝트에서 기본으로 사용 | [Codex·Paseo 개인 공통 연결](runtime/global-workflow.md) |
| 프로젝트 하나에 연결하거나 직접 설치 | [처음 시작하기](GETTING_STARTED.md) |

연결 후에는 “이 오류를 고치고 관련 테스트까지 확인해줘”처럼 평소대로 요청하면 됩니다.

## 무엇을 할 수 있나요?

- **요청 판단·역할 선택:** 직접 처리할지, 필요한 역할·검토·위임을 사용할지 판단합니다.
- **실행·검증·마감:** 환경의 공식 실행 경로와 한도를 따르고 결과·검증 근거를 연결합니다.
- **기록·개선:** 지원되는 측정 구간의 사용량을 조회하고, 여러 PC의 최소 결과 요약을 파일로 모을 수 있습니다.

기능은 필요한 작업에서 선택해 사용합니다. [기능별 연결 항목과 지원 범위](runtime/project-onboarding.md#기능별-연결-확인)를 확인하세요.

## 알아둘 점

- 앞단 판단은 연결된 현재 AI가 수행합니다. 메시지 복사만으로 설치·모델 전환·위임·수집이 자동 완료되지는 않습니다.
- 앱별 지원이 다릅니다. 현재 대화의 자동 모델 전환, Paseo·Codex 앱 자동 수집 adapter와 중앙 업로드는 미구현입니다. 실제 측정하지 않은 값은 미측정으로 표시합니다.
- 기존 프로젝트 지침과 작업을 보존합니다. 실제 대화·계정·키·DB·개인 경로는 공개하지 않습니다.
