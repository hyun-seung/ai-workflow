# RP-02 — 같은 주제의 후속 질문

가상 대화 두 턴 전체가 한 사례다. 각 방식에서 첫 답을 생성한 다음 두 번째 사용자 입력을 전달한다. RP-01이나 반대 방식의 응답을 첫 답으로 재사용하지 않는다.

## 실행 입력

첫 번째 사용자 입력:

> `a = [[1], [2]]; b = a.copy()`에서 무엇이 복사되는지 핵심만 2문장으로 설명하고 공식 근거를 연결해 줘. 퀴즈와 추가 Q&A는 생략해 줘.

두 번째 사용자 입력:

> 그럼 `b[0].append(9)`를 하면 a도 바뀌는 이유만 한 문장으로 말해 줘. 앞에서 한 정의는 다시 설명하지 않아도 돼.

## 공통 완료 기준

| ID | 필수 기준 |
| --- | --- |
| AC-01 | 첫 답은 새 바깥 리스트와 공유하는 안쪽 리스트를 구분한다. 본문 2문장과 관련 공식 근거를 제공한다. |
| AC-02 | 후속 답은 안쪽 리스트가 공유된다는 인과를 한 문장으로 설명한다. 모든 복사가 완전히 독립적이라고 확대하지 않는다. |
| AC-03 | 후속에 긴 정의·Q&A·퀴즈·새 추천을 덧붙이지 않는다. 앞에서 확인한 같은 범위의 공식 근거는 재사용할 수 있다. |
| AC-04 | 같은 주제의 후속으로 처리하며 유효한 기존 선택이 있으면 재사용한다. 새 사용자 선택이나 실제 모델 전환이 있었다고 만들지 않는다. |
| AC-05 | 두 응답·그 사이 제어/선택 처리·검증·재작업을 같은 방식의 요청에 포함한다. 첫 답 비용을 빼고 후속만 비교하지 않는다. |

## 판정 근거

[Python 3.14 `list.copy()`](https://docs.python.org/3.14/tutorial/datastructures.html#more-on-lists)와 [공식 `copy` 설명](https://docs.python.org/3.14/library/copy.html)의 얕은 복사 범위를 대조한다. 짧은 후속의 제어 기준은 프로젝트의 [튜터 진입 요약](../../../learning/tutor-brief.md)을 따른다.
