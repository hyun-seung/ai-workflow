# RP-01 — 짧은 개념 설명

가상 입력·공통 완료 기준이다. 양쪽 방식에 이 파일의 입력과 기준만 동일하게 전달한다. 기준 파일의 해시는 실행 전에 고정한다.

## 실행 입력

> Python에서 아래 코드를 실행하면 왜 a도 바뀌어? 처음 배우는 사람에게 쉽게 설명해 줘. 본문은 5문장 이내, 이어서 궁금할 질문과 답은 1쌍만 붙여 줘. 공식 문서의 관련 절 링크도 연결해 줘. 퀴즈나 그림은 필요 없어.

```python
a = [1, 2]
b = a
b.append(3)
```

## 공통 완료 기준

| ID | 필수 기준 |
| --- | --- |
| AC-01 | 실행 후 두 이름으로 `[1, 2, 3]`을 보게 되는 이유를 같은 리스트 참조로 설명한다. 대입이 독립 복사라고 하지 않는다. |
| AC-02 | 처음 쓰는 전문 용어는 풀어 쓰고, 비유를 쓴다면 실제 동작과 구분한다. 본문 5문장 이내다. |
| AC-03 | 관련 질문과 답이 정확히 1쌍이며 사용자에게 답을 요구하는 퀴즈로 바꾸지 않는다. |
| AC-04 | 핵심 주장을 뒷받침하는 공식 문서의 해당 페이지/절을 실제 확인해 링크한다. 링크만 있고 주장과 맞지 않으면 통과가 아니다. |
| AC-05 | 양쪽에 적용한 모델 고정·위임 금지·최신 제어를 지킨다. 역할 지침을 사용했다는 이유로 승인 질문·모델/worker를 추가하지 않는다. |

소규모 설명에서 추천이 없다는 것과 튜터식 설명을 생략하는 것은 다르다. 정책 결과와 설명 품질을 각각 기록한다.
